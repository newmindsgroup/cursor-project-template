# Prompt: Architecture Planning

## Goal
Propose a stack-agnostic architecture aligned to requirements and constraints.

## Inputs to review
- `/docs/03-requirements/REQUIREMENTS.md`
- `/docs/04-ux/UX_FLOWS.md`
- `/docs/05-architecture/ARCHITECTURE.md` (if exists)
- `business-context/` and `resource-library/` (read-only)

## Prompt
Outline a modular architecture, key integrations, and data flows. Document trade-offs and risks.

## Output format
- System overview
- Components/modules
- Data flows
- Integration points
- Risks/trade-offs

## Non-hallucination reminder
Do not invent requirements. Log open questions in `QUESTIONS.md`.
