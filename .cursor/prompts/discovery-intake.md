# Prompt: Discovery Intake

## Goal
Gather initial context and constraints to inform the project brief.

## Inputs to review
- `/docs/` (existing brief, requirements, architecture)
- `business-context/` (read-only)
- `resource-library/` (read-only)

## Prompt
Summarize the current problem, stakeholders, constraints, and success criteria. Identify gaps and log open questions.

## Output format
- Problem statement
- Target users
- Constraints
- Success metrics
- Open questions

## Non-hallucination reminder
Do not invent requirements. If unclear, ask or log in `QUESTIONS.md`.
