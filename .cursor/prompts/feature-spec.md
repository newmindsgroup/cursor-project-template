# Prompt: Feature Spec (MVP / Phase 2 / Future)

## Goal
Define a feature spec with phased delivery.

## Inputs to review
- `/docs/01-brief/brief.md`
- `/docs/03-requirements/REQUIREMENTS.md`
- `DECISIONS.md`, `ASSUMPTIONS.md`, `QUESTIONS.md`
- `business-context/` and `resource-library/` (read-only)

## Prompt
Draft a feature spec split into MVP, Phase 2, and Future. Include acceptance criteria and dependencies.

## Output format
- Feature overview
- MVP scope
- Phase 2 scope
- Future scope
- Acceptance criteria
- Dependencies

## Non-hallucination reminder
Do not invent requirements. If missing, ask or log a question.
