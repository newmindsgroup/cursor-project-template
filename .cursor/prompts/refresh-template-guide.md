# Prompt: Refresh Template Guide

## Goal
Keep `TEMPLATE_GUIDE.md` aligned with the current repository structure, workflows, and prompts.

## Inputs to review
- `/docs/` (all phases)
- `/.cursor/prompts/`
- Root documentation files (project, scope, decisions, assumptions, questions)
- `CHANGELOG.md`

## Prompt
Re-scan the repository structure and update `TEMPLATE_GUIDE.md` so it reflects any new prompts, workflows, or files. Keep the guide concise and standardized. Maintain a changelog note in `CHANGELOG.md` describing the template guide update. Avoid referencing specific filenames inside the reference folders.

## Output format
- Updated `TEMPLATE_GUIDE.md`
- Changelog note in `CHANGELOG.md`
- Brief summary of changes

## Non-hallucination reminder
Do not invent requirements. If unsure, ask or log questions.
