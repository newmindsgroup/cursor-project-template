# Security

## Baseline Practices
- [ ] Store secrets in environment variables or a secret manager
- [ ] Do not commit secrets or credentials
- [ ] Classify and protect sensitive data (PII/PHI/PCI)
- [ ] Minimize data retention
- [ ] Apply least-privilege access
- [ ] Log safely (no secrets)
- [ ] Document auth, authz, and audit needs
- [ ] Threat-model high-risk flows

## Disclosure Policy
- Please do not open public issues for security vulnerabilities.
- Report suspected vulnerabilities using the contact method below.
- Provide enough detail to reproduce and assess impact.
