# Kickoff Checklist (New Project)

Use this list when starting a new project from this template.

## Setup
- [ ] Create the new repo (or use GitHub “Use this template”).
- [ ] Clone locally and open `project.code-workspace`.
- [ ] Confirm `TEMPLATE_VERSION` (optional: note in `CHANGELOG.md`).

## Project identity
- [ ] Fill `PROJECT.md` (single source of truth).
- [ ] Update `SCOPE.md` (in/out/constraints).
- [ ] Add any known stakeholders, open questions, and assumptions.

## Local reference context (read-only inputs)
- [ ] Add local business context materials to `/business-context/` (do not commit sensitive files).
- [ ] Add local reference materials to `/resource-library/` (do not commit sensitive files).

## Autofill run
- [ ] Follow `/docs/09-ops/autofill-workflow.md` to populate docs from folder-level reference sources.
- [ ] Confirm unknowns are logged in `QUESTIONS.md` (no guessing).

## Confirm scope and plan
- [ ] Ensure `/docs/01-brief/brief.md` is complete.
- [ ] Ensure `/docs/03-requirements/REQUIREMENTS.md` has an MVP section with acceptance criteria.
- [ ] Ensure `/docs/04-ux/ux-flows.md` covers primary flows and screens.
- [ ] Ensure `/docs/05-architecture/ARCHITECTURE.md` has initial placeholders + risks.
- [ ] Update `ROADMAP.md` with an initial sequence.

## Before writing product code
- [ ] Confirm `PROJECT.md + SCOPE.md + REQUIREMENTS.md` are minimally clear.
