# Business Operating System Context

This document positions the website project within the context of the client's overall business operating system. The website is one cornerstone—not the entire building.

## Purpose

This template helps:
- Frame website work as part of holistic business development
- Identify how website connects to other business systems
- Ensure website scope accounts for business maturity
- Guide conversations beyond "just a website"

## When to Use

- During project kickoff to set proper context
- When scoping website features and integrations
- When recommending additional consulting services
- To educate clients on website's role in business success

## Pillar 1: Leadership

**Function:** Cast vision, align team, make decisions

### Current State Assessment

```
Leadership clarity score: ___/10

Key indicators:
- [ ] Mission statement exists and is communicated
- [ ] Vision for 3-5 years is articulated
- [ ] Core values are documented and lived
- [ ] Team is aligned on direction
- [ ] Decision-making process is clear
```

### Website Connection

| Leadership Element | Website Manifestation |
|-------------------|----------------------|
| Mission | About page, messaging throughout |
| Vision | Brand positioning, aspirational content |
| Values | Tone, imagery, commitments displayed |
| Team alignment | Consistent voice across all pages |

### Gaps That Affect Website

If leadership is unclear:
- [ ] Messaging will be inconsistent
- [ ] Approvals will be slow or contradictory
- [ ] Brand voice will be undefined
- [ ] Long-term content strategy will lack direction

### Website Can Help With

- **Marketing**: Lead generation, brand awareness, content delivery
- **Sales**: Lead qualification, appointment booking, proposals
- **Operations**: Client communication, self-service, status updates
- **Cash Flow**: Online payments, subscriptions, e-commerce

### Website Cannot Fix

- **Leadership**: Vision, mission, team alignment
- **Products**: What you sell, how you deliver, quality
- **Operations**: Internal processes, team management
- **Cash Flow**: Profitability, financial management

## Recommendations Based on Assessment

### If Leadership is Weak (Score < 4)

**Before website:**
- Clarify mission and vision
- Define core values
- Align stakeholders on direction

**Website scope adjustment:**
- Budget extra time for messaging approval
- Expect content revisions
- Plan for brand development

### If Marketing is Weak (Score < 4)

**Before website:**
- Define target audience clearly
- Develop core messaging (StoryBrand)
- Create lead magnet concept

**Website scope adjustment:**
- Include messaging development
- Plan lead capture strategy
- Budget for content creation

### If Sales is Weak (Score < 4)

**Before website:**
- Document sales process
- Implement or plan CRM
- Define conversion goals

**Website scope adjustment:**
- Keep conversion paths simple
- Plan CRM integration
- Include calendar/booking

### If Products are Weak (Score < 4)

**Before website:**
- Clarify offerings and pricing
- Document delivery process
- Gather customer success stories

**Website scope adjustment:**
- Focus on fewer offerings
- May need copywriting support
- Case study development

### If Operations is Weak (Score < 4)

**Before website:**
- Document key processes
- Plan capacity for growth
- Systematize delivery

**Website scope adjustment:**
- Don't oversell capability
- Start with basic features
- Plan for future automation

### If Cash Flow is Weak (Score < 4)

**Before website:**
- Set realistic budget
- Plan for ongoing costs
- Consider phased approach

**Website scope adjustment:**
- MVP approach
- Focus on high-impact features
- Clear ROI expectations

## Project Scope Recommendations

Based on overall assessment:

### Strong Foundation (48-60)

**Recommendation:** Full website build
- Comprehensive features
- Advanced integrations
- Content marketing foundation
- Conversion optimization

### Moderate Foundation (36-47)

**Recommendation:** Website + business development
- Core website features
- Essential integrations
- Parallel work on weak pillars
- Phased feature rollout

### Weak Foundation (24-35)

**Recommendation:** Foundation-first approach
- Minimal viable website
- Focus on key conversions
- Business development priority
- Plan for website evolution

### Critical Gaps (< 24)

**Recommendation:** Business development first
- Landing page only (if urgent)
- Focus on business fundamentals
- Return to website when ready
- Consulting engagement instead

## Key Principle

> The website is a powerful tool, but it's one tool in a larger system. A beautiful website built on a weak business foundation is like a billboard in the desert—impressive but ineffective.

Success comes from:
1. Understanding the whole business system
2. Building appropriate website for current maturity
3. Addressing business gaps alongside website work
4. Evolving website as business matures
