# Launch Checklist (Canonical)

## Prelaunch
- [ ] Confirm scope and acceptance criteria are complete.
- [ ] Validate monitoring/alerts ownership.
- [ ] Confirm rollout plan and rollback plan.
- [ ] Confirm stakeholder comms plan.
- [ ] Confirm legal/compliance/security sign-offs (if needed).

## Launch
- [ ] Deploy/enable release.
- [ ] Verify critical paths.
- [ ] Verify monitoring signals.
- [ ] Announce launch to stakeholders.

## Postlaunch
- [ ] Monitor for regressions.
- [ ] Collect feedback and log follow-ups.
- [ ] Update `DECISIONS.md` with any launch-time decisions.
- [ ] Update `CHANGELOG.md` for release notes (if applicable).
