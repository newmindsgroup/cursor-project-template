Understanding Your Users

These UX assets help ensure we're building the right website for your target audience. Review the personas, user flows, and journey maps to align on user needs and expectations.

Progress UX Assets Wireframes

User Personas

Personas represent your key user types. Each persona includes their goals, frustrations, and jobs-to-be-done (JTBD) to guide design decisions.

User Flows

User flows map out the key paths users take through the website to accomplish their goals. Each flow identifies the screens, actions, and success/failure states.

Customer Journey Maps

Journey maps show the complete customer experience across touchpoints, from initial awareness through ongoing engagement. They highlight emotional states and opportunities for improvement.

How to Use These UX Assets

1

Review Personas

Understand who the website is for. Each design decision should serve these user types.

2

Trace the Flows

Verify the website supports each user flow. Test the critical paths during QA.

3

Validate Experience

Use journey maps to ensure the full customer experience is considered, not just the website.

Provide Feedback

Do these personas accurately represent your users? Are there user flows we're missing? Your feedback helps us build a better website.
